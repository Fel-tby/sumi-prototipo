# Supabase

Este diretório mantém migrações e configurações versionadas relacionadas ao banco de dados.

## Regras

- Toda alteração de estrutura deve ser registrada por migração.
- Migrações aplicadas não são reescritas.
- Dados reais não são incluídos no repositório.
- Dados de desenvolvimento devem ser sintéticos ou previamente autorizados.
- Chaves administrativas permanecem em variáveis de ambiente do backend.
